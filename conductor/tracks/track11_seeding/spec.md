# Track 11: Product Seeding

## Objective
Create an automated script logic to populate the Firestore `products` collection with 50 unique items spanning across 5 categories to give the MagicSystem Shop a realistic dataset.

## Requirements
- Since node cannot run TS Next.js imports cleanly without `ts-node` or `tsx`, implement a Next.js API route `app/api/seed/route.ts` that will act as our seeder. 
- Generating the products requires 5 Categories (e.g., Electronics, Clothing, Home, Books, Beauty).
- Each product must conform to `Product` interface (`id` will be generated by Firestore, `title`, `description`, `price`, `imageUrl`, `category`, `stock`, `createdAt`).
- Due to the high complexity of setting up Cloudinary via the raw API within a mock, we will seed using dynamic realistic Unsplash Source URLs based on the category (e.g. `https://source.unsplash.com/400x400/?electronics`).
- The API route should clear existing products first (or just blindly append 50 items on trigger).
